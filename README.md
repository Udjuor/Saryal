# Kerdiis School

Школьная версия Kerdi:s для одного класса. Учитель отмечает на уроке, кто пришёл, кто опоздал и почему отсутствует, а программа сама собирает отчёт за месяц для мониторинга посещаемости и дисциплины.

Автор: Кэрэчээнэ Семёнова.

## Что умеет

- **Сегодня.** Уроки дня по расписанию звонков и недели. Текущий урок выделен маркером, у прошедших видно, сколько учеников было, сколько опоздало и сколько отсутствовало.
- **Отметка на уроке.** «Все пришли» отмечает весь класс одной кнопкой. Затем у отдельных учеников ставится «Опоздал» со временем прихода, «Болеет», «Уважительная», «Освобождён» или «Нет».
- **Расписание.** Звонки, предметы по дням недели, пяти- или шестидневка, даты учебного года, каникулы. Замена или отмена урока в отдельный день делается кнопкой «Изменения на этот день».
- **Класс.** Список учеников (можно вставить столбцом из Excel или Word), дата выбытия, классный руководитель, школа.
- **Отчёт за месяц.** Итоги по каждому ученику и классу, таблица по дням с буквами причин. Сохранение в Excel и PDF, печать.
- **Питомец класса.** Здоровье питомца зависит от посещаемости.
- **Языки:** якутский, русский, английский. **Вид:** тетрадь в клетку или школьная доска.

## Правила учёта

| Ситуация | Статус |
| --- | --- |
| Пришёл до начала урока или в первые 4 минуты | Был |
| С 5-й по 19-ю минуту после начала | Опоздание (минуты считаются) |
| С 20-й минуты | Пропуск без причины |
| «Болеет» | Пропуск по болезни, ждём справку, пока не нажата «Справка принята» |
| «Уважительная», «Освобождён» | Пропуск по уважительной причине |
| Урок закончился, отметки нет | Без причины |

Отсчёт идёт от фактического начала урока. Если учитель задержался и нажал «Начать урок» позже звонка, ученики, пришедшие до него, не опоздали. Если кнопку не нажимали, отсчёт идёт от звонка. Уроки, на которых не поставили ни одной отметки, в отчёт не попадают.

В таблице по дням: число пропущенных уроков и буква причины. «н» значит без причины, «б» болезнь, «у» уважительная, «осв» освобождён, «оп» опоздание.

## Где данные

Всё хранится только на этом компьютере, в профиле учителя: `%APPDATA%\Kerdiis School\data.json`. Сеть не нужна. Каждый день программа сама делает копию в папку `backups` рядом и хранит последние 30. В «Настройках» можно сохранить копию на флешку и восстановить данные из копии.

## Установка

Скачайте `Kerdiis-School-Setup-<версия>.exe` со страницы релиза и запустите. Права администратора не нужны: программа ставится для текущего пользователя, ярлык Kerdiis School появится на рабочем столе. Новая версия ставится тем же установщиком поверх старой, данные сохраняются.

Установщик пока не подписан сертификатом. Если Windows предупредит о неизвестной программе, нажмите «Подробнее», затем «Выполнить в любом случае».

## Переводы

Все фразы интерфейса лежат в таблице `i18n/phrases.tsv` со столбцами ru, sah и en, разделёнными табуляцией. После правки таблицы пересоберите словари командой `node scripts/build-locales.mjs`. Тест `test/i18n.test.mjs` проверяет, что переведена каждая фраза.

## Разработка

```
npm install
npm start              # запуск
npm test               # модульные тесты
npm run dist           # установщик в dist/
```

Сквозная проверка со снимками экрана: `node scripts/e2e.cjs`. Ей нужен Playwright, путь к Electron передаётся через `CAL_EXE`, а `KERDIIS_HOME` и `KERDIIS_CLOCK` задают отдельную папку данных и часы.

Сборка установщика идёт в GitHub Actions на Windows. При метке `v*` установщик прикладывается к релизу.
